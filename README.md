# Latihan 1: Proyek Toko Buah - SB Admin (PBKK-2)

Proyek ini mengintegrasikan seluruh 7 sub-bab modul Latihan 1 dari silabus perkuliahan:
1. **2-1:** Instalasi dan Konfigurasi CI (Base URL, Autoload, Database SQLite)
2. **2-2:** Fungsi Router dan Controller (About, Contact, Overview, Products, Login, Logout)
3. **2-3:** Menggunakan Bootstrap untuk View Aplikasi pada CI
4. **2-4:** Menggunakan Template Bootstrap SB Admin (Struktur Partials: Head, Navbar, Sidebar, Breadcrumb, Footer, Modal, JS)
5. **2-5:** Mengenal Model dan CRUD (Tabel Produk: Create, Read, Update, Delete)
6. **2-6:** Penanganan File Upload (Upload gambar produk ke folder `upload/product/`)
7. **2-7:** Mengatur Akses User (Autentikasi Session, Halaman Login, Proteksi Akses, Logout)
